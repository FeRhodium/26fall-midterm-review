Objective
• Apply relaxations in a “smart” way to avoid O(VE) of
  Bellman-Ford.

  to do relaxations only once -> O(V+E).
• Dijkstra’s algorithm: smart way to relax edges only once, for
  general graphs with non-negative edges → 𝑂(𝑉 log 𝑉 + 𝐸).

The case of directed acyclic graphs (DAGs)
• We can find the order of relaxations to be performed once by running
  topological sort!
                                                                Consider the nodes in decreasing
                                                               post values; relax all outgoing edges




• There is no cyclic dependence in solving the Bellman equations.
• The shortest distance of a node depends only on values of previous nodes.

Complexity
• Topological sort takes time Θ(𝑉 + 𝐸) using a Depth First Search..
• Then, time spent on DAG: one visit per state, each incoming edge relaxed
  exactly once, hence Θ(𝑉 + 𝐸).
• Total: Θ(𝑉 + 𝐸).

Dijkstra with negative weights
• Running Dijkstra: finding 𝑡 does not imply a shortest path.
• Why? because nodes in 𝑆 are not necessarily stable:
• Using a negative edge might offer better paths to nodes in 𝑆;
   • If a node in 𝑆 strictly improves its estimate, it must go back to 𝑄 to be processed
     again and update the values of other nodes it can reach.
• Must wait until all nodes in 𝑆.
   • This will happen eventually (if no negative cycles), and it will give us the right
     shortest paths.
• Hence, no guarantee to terminate in 𝑁 − 1 steps.

Conclusions
• Dijkstra’s algorithm: smart way of relaxing only edges of nodes in the
  shortest path tree in the right order.
• Needs non-negative weights.
• Extends BFS: keep exploring nodes that are closest to 𝑠.
• Not efficient if I want to find SP to a specific node 𝑡.

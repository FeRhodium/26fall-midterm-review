How to use this page with the chat
  1. Start by doing nothing here. The chat will tell you when to press a button. The first time will be "press button 1".
  2. The chat asks you a question about the graph below. Work it out yourself and answer it in the chat.
  3. Only then, press the numbered button the chat tells you to press (for example "button 3"). That picture appears in its place, next to the earlier ones, so you can see what changed.
  4. Do not press other buttons ahead of the chat: each picture shows the answer to a step.
How to read the pictures (please read this before you start)
In every picture each circle shows the node name and, below it, the node's current distance estimate d (∞ means no path found yet). Blue arrows are the current predecessor pointers π.
Bellman-Ford:amber: d improved in this round
Dijkstra:white: not reached, d = ∞amber: open, a distance is found, still waiting in Qgreen: finished, in Sblue ring: just extracted

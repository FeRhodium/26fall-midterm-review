A-Star line stepper

How to use this page with the chat
  1. Start by doing nothing here. The chat tells you when to press a button, and in which section.
  2. The chat asks a question about the graph below. Work it out yourself and answer in the chat.
  3. Only then press the numbered button the chat names. The picture appears below, and earlier pictures stay on screen so you can compare.
  4. Do not press ahead of the chat: each picture shows the answer to a step.
How to read the pictures (please read this before you start)
In the runs, each row shows the line after one extraction. Each circle shows the node name above it and, inside, the node's current distance d (∞ means not reached yet). In Runs 2 and 3 the small number under an open node is its key d + h. Blue arrows are the current predecessor pointers (π). In the section on the new weights, the circles show the new distance d′.
white: not reached, d = ∞amber: open, a distance is found, still waiting in Qgreen: finished, in Sblue ring: just extracted
In the section New weights, blue arrows have weight 0 and grey arrows weight 2.
The graph. A line of 9 nodes. The source is s in the middle, the target is A at the right end. Every edge has weight 1 and can be used in both directions. Distances from s are the number of steps. The node 2, halfway between s and A, is called M; we use it later.
Tie rule for the whole session: if two open nodes have the same key, extract the one further to the left first.
Notation: d(v) is the distance found so far (the lecture slides call it g(v)). The key d + h is called f(v) in the slides.

Run 1: plain Dijkstra, key = d

Each row is one step: extract the open node with the smallest key, then relax its two edges. The run continues until every node is extracted.

The distances d are updated by relax exactly as before. Only the choice of the next node to extract uses the key d + h. The number under an open node is its key.

New weights: w′(u→v) = w(u→v) + h(v) − h(u)

Each pair of neighbouring nodes has two arrows: the top one points right (weight above it), the bottom one points left (weight below it). Blue arrows have weight 0, grey arrows weight 2. Two buttons, one per choice of h.

Plain Dijkstra on the new weights

The key is d′ only, with no h any more. Each circle shows the new distance d′. Two buttons, one per choice of h.

Summary: how the search moves through the tree

The tree is the same line in every case. Each picture shows it growing from s: one row per extraction, going down. Green nodes are in S, blue segments are the tree edges added so far, and the newest edge is thicker.

• Uniform Cost Search:
  A goal-oriented BFS

Objective
• Extend BFS to find shortest paths from origin 𝑠 to a given destination 𝒅 for arbitrary link
  weights. In classical BFS edges have unit distance (“hops” count).
• New interpretation: build a set of paths starting from 𝑠 instead of a set of nodes.
• At the end of step 𝑘 − 1: 𝑃𝑘−1 = current “potentially interesting” set of paths (if 𝑑 is
  reachable, then one of these path is the prefix of the shortest path we are searching for).
• In step 𝑘 we add more paths by expanding the most promising among the current paths:
                                  ∗
  we choose the shortest path 𝜋𝑘−1    from 𝑃𝑘−1 , remove it out from the current set, and add
  the new paths that result by adding the neighbours of its leaf (final node). If we reach 𝑑,
  we record the path length 𝑤 ∗ . We found a feasible path, but perhaps we can do better!
• We keep expanding 𝑃ℓ , ℓ > 𝑘 by always expanding its shortest path while improving our
  shortest path length 𝑤 ∗ when possible. We terminate if all candidate paths are ≥ 𝑤 ∗ .
• Classic BFS: Think of the queue as containing the leaves of the potentially interesting paths.
  Key difference: the first time we reach 𝑑 in classic DFS we can stop (no way to beat that)

 Graph representation
• To solve graph problems, must examine graph.
• Need to represent in computer.
• Four representations with pros/cons.
   • Adjacency lists (of neighbors for each vertex).    similar
   • Incidence lists (of edges from each vertex).
   • Adjacency matrix (0-1, which pairs are adjacent).
   • Implicit representation (as a “find neighbor” function).

Adjacency list
• For each vertex 𝑣, list all its
  neighbors (vertices to which it is
  connected by an edge).
  •   Array 𝐴 of |𝑉| linked lists.

      neighbors {𝑢| 𝑣, 𝑢 ∈ 𝐸}.

  outgoing neighbors.

  edge information in two places

Code Tree Costs

A file is written with a few symbols. Each symbol gets a code word of 0s and 1s, read off a binary tree. Which tree writes the file in the fewest bits? Read the story below, then work through the tabs. If you are following a chat session, answer there first and press Next afterwards.

Before you start

The story

A long file is written using only a few symbols, say A, B, C and D. In the file, A appears 8 times, B appears 4 times, and so on. The number of times a symbol appears is its frequency.

Here is such a file, 16 symbols long: A A B A C A B A D A A B C A B D. A appears 8 times, B 4 times, C 2 times and D 2 times. Writing it down means replacing every symbol by a string of bits, and we want the final string to be as short as possible.

To store the file we replace each symbol by a code word, a string of 0s and 1s, and we want the whole file to take as few bits as possible. To be able to read the file back without confusion, we draw a binary tree and put the symbols at its leaves. The code word of a symbol is the path from the top of the tree, the root, down to its leaf: write 0 for a step to the left and 1 for a step to the right. No code word can then be the beginning of another.

The cost of a tree is the number of bits needed to write the whole file with its code words. We are looking for a tree with the lowest cost.

Words used here

  • Symbol and frequency: a letter, and how many times it appears in the file.
  • Leaf: a box with a symbol and its frequency. Internal node: a circle, any node that is not a leaf, the root included.
  • Frequency of an internal node: the sum of the frequencies of the leaves below it.
  • Depth of a node: the number of steps from the root down to it. It is also the length of the code word of a leaf.
  • Cost of a tree: for each symbol, its frequency times its depth, all added up. This is the number of bits of the file.
  • Merge: take two trees and put them under a new internal node. The frequency of the new node is the sum of the frequencies of the two trees.

The tabs

  • Cost of a tree: two different trees for the same four symbols. Work out the cost of each in two ways, from the leaves and from the internal nodes.
  • Merge view: build a tree from the bottom, one merge at a time, and watch the cost grow as you go.
  • Merge game: you choose which two trees to merge. Try to reach the lowest cost you can, on three data sets.
  • Take them from left to right, or follow your chat session.

The buttons

  • On the first two tabs, Next shows the next step, Back goes one step back and Restart returns to the first step.
  • Check your answer shows the numbers that the chat has just asked you for. Press it only after you have answered in the chat.
  • The Earlier steps strip at the bottom keeps a small picture of every step you have seen. Click one to jump back to it.
  • On the game tab, click the top node of a tree to select it, then click a second tree to merge the two. Undo takes back the last merge and Restart starts the data set again.
  • The ← and → keys also step back and forward on the first two tabs.

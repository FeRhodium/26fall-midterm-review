What is “greedy”?
• Myopic behavior is easy and convenient, attractive for designing
  algorithms.
• Greedy algorithms: build up a solution piece by piece, always choosing
  the next piece that offers the most obvious and immediate benefit.
• This is not always sensible, but there are some computational tasks for
  which it is optimal to be greedy.

Properties
• Property 1: Removing a cycle edge cannot disconnect a graph that was
  connected.
• Property 2: A tree on 𝑛 nodes has 𝑛 − 1 edges.
   • Algorithm: start with all nodes disconnected, defining each a connected component.
     Keep adding each edge (𝑢, 𝑣) making sure 𝑢 and 𝑣 are in separate connected
     components, hence reducing the total number of connected components by one.
• Property 3: Any connected undirected graph 𝐺 = (𝑉, 𝐸) with |𝐸| = |𝑉 | − 1 is
  a tree.
• Property 4: An undirected graph is a tree if and only if there is a unique path
  between any pair of nodes.

Prim’s algorithm
• Prim’s algorithm: the intermediate set of edges 𝑋 always forms a subtree,
  and 𝑆 is chosen to be the set of this tree’s vertices.
• Strongly reminiscent of Dijkstra’s algorithm:
   • in Prim’s, the value of a node is the weight of the lightest incoming edge from set 𝑆.
   • in Dijkstra’s it is the length of an entire path to that node from the starting point.

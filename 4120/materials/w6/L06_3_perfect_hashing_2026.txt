Conclusions
• We constructed a “static” data structure for checking membership for a
  given set of keys.
• There are generalizations we did not cover.
    • Easy generalization when new keys are inserted in the set
    • In this case we may need to rehash in the case of collisions in the first
      hash table.
    • But the amortized cost per operation is still O(1).

Objective
• Given an algorithm, a certain operation type, e.g., insert(x), and an execution
  history of the system, while this operation at certain times may have a significant
  cost in resources, at other times it may not be as costly.
• Looking at the worst-case run time per operation, rather than the average per set
  of such operations when performed for any given input sequence, can be too
  pessimistic.
• The amortized analysis relates together the more costly and less costly same type
  operations during system histories, if these balance each other. It assigns a fixed
  representative cost to each operation, the “amortized cost”, that its sum covers
  the total actual cost generated by these operations at all points in time, for any
  system execution.
• Reference: CLRS Ch. 17, Erik Demaine MIT slides on amortized analysis.

Amortization methods
• Central concept: allow an operation to deposit (or get back) money using some
  bank account besides paying for the actual cost (note: account cannot become < 0).
   • Op. 𝑖 stores credit: amortized_cost 𝑖 > actual_cost(𝑖) (part of am. cost goes to bank).
   • Op. 𝑗 uses credit: amortized_cost 𝑗 < actual_cost(𝑗) (part of act. cost is subsidized).
   • This is a general principle in all methods using amortized costs.
• Possible methods:
   • Aggregate method, accounting method, charging method, potential method.
• Different ways to construct the proof of correctness (i.e., that total amortized
  cost covers always total actual cost).
• We give different interpretations of how to construct the amortized costs. That
  helps us with the steps of the proof.

Conclusions
• The same operation on the data structure might have different cost at different times
  because of the different state of the data structure.
• It is not fair to always associate the worse case cost since this might be always
  balanced with a long period of low costs.
• Idea: define the “amortized cost” of an operation: a value that is usually constant
  over time. We think that operations pay this amount each time they are invoked.
• Challenge: make sure that at each time the accumulated total amortized cost covers
  the total actual cost.
• Why? because then we know for sure that the average actual cost per operation
  averaged over any time horizon and any execution is less than the amortized cost =
  Θ(1).
• How to guess a correct amortized cost? many different methods!
